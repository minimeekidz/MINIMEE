# 主題詞彙貼紙（144 個詞，139 個檔）

由 Em 嗰 9 張 sticker sheet 切出嚟：

```
node scripts/cut-theme-stickers.mjs <放住 9 張 sheet 嘅資料夾>
```

**檔名就係個詞** —— `港鐵.webp` 就係 港鐵 嗰個貼紙，同其他 sticker pack 一樣，
唔使填表。

## 點解係 139 唔係 144

有五個詞喺兩個主題都出現（例如 `機器人` 喺 12 未來智慧城 同 28 AI與機器人，
`花朵` 喺 08 綠色公園 同 20 植物的秘密），所以 144 格出 139 個檔。
呢個係正常，唔係漏咗 —— 個 script 有 check，跌穿 130 就會拋錯。

## 佢哋自己帶住個詞

Em：「我已經生成咗一啲小圖片連文字嘅 Sticker，可以用來選擇答案嘅時候用」。
所以個字係貼紙嘅一部分，唔會剪走 —— 呢個正正係令一個仲學緊字嘅細路仔
撳得落手嘅原因。

## 要換／要補

同名覆蓋就得。9 張 sheet 唔係按主題順序排嘅（檔名嗰個 `(1)`–`(9)` 只係
下載編號），真正對應寫咗喺 script 個 `SHEETS` 度：
`(1)`→主題 1、`(2)`→13、`(3)`→33、`(4)`→9、`(5)`→5、`(6)`→29、
`(7)`→25、`(8)`→21、`(9)`→17。

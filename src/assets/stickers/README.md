# 貼紙包 Sticker packs

放貼紙落嚟就得，唔使改 code，唔使叫人重新 build 一次清單 —— 個網會自動搵到。

## 點放

```
src/assets/stickers/
  interest/   興趣      畫畫.webp  踢波.webp  睇書.webp …
  activity/   活動      游水.webp  露營.webp  跳舞.webp …
  job/        職業      醫生.webp  太空人.webp  廚師.webp …
  mood/       心情      開心.webp  嬲.webp  攰.webp …
```

**個檔案名就係個標籤。** `畫畫.webp` 喺網頁度就會顯示做「畫畫」。所以：

- 用中文改檔名，寫返你想小朋友見到嗰個詞。
- 唔好加編號或者英文前綴（`01-畫畫.webp` 會變成標籤「01-畫畫」）。
- 一個詞一個檔。同一個詞唔好喺兩個資料夾度出現。

## 點解檔名咁重要

小朋友喺自我介紹卡揀「畫畫」嘅時候，張卡會自動配返 `interest/畫畫.webp` 出嚟。
即係話**貼紙同文字係靠個名夾返一齊**，唔使另外開一張對照表俾人維護，
亦都唔會出現「加咗貼紙但係冇人接上去」嘅情況。

呢個亦都係小寵物出問題嗰陣用嘅圖：小寵物問「🎨 ＝ ？」嗰個 🎨 就係呢啲貼紙。
所以**每個學習詞語最好都有一張同名貼紙**，唔係嘅話小寵物只可以出文字題。

## 格式

- `.webp` 最好（細）、`.png` 同 `.svg` 都收。
- 正方形，建議 512×512。
- **去咗底**（透明背景）。白底會喺深色場景度變成一嚿白方格。

## 未剪開嘅原稿貼紙集唔好放喺呢度

一張圖入面有成 8 隻小動物嗰啲「貼紙集／拼圖」原稿，係**素材**，唔係貼紙。
放咗入嚟嘅話，個網會當佢係一張叫「像素萌寵旅行與日常貼紙集」嘅貼紙俾小朋友揀。

原稿請放 `docs/source/sticker-sheets/`，剪開之後一個概念一個檔先放入呢四個資料夾。

# 小寵物送嘅 MEE 卡

呢啲卡**同平時收集嘅 MEE 卡唔同**，所以擺喺呢度，唔好同 `card-*.webp` 撈埋。

```
src/assets/pet-cards/
  normal/   普通版   Lv.6 開始，小寵物隨機送
  flash/    閃耀版   Lv.8（最好嘅朋友）先至送
```

**檔案名就係張卡個名**：`海浪之友.webp` → 卡名「海浪之友」。

## 點解可以重複

平時收集嗰啲 MEE 卡係唔可以重複攞嘅（`mee_cards` 有 unique constraint 擋住，
因為第 5 條規則寫明張卡唔可以重抽）。

小寵物送嘅卡**故意冇呢個限制** —— 你講明重複咗係可以轉送俾好友冊入面嘅朋友，
所以資料庫嗰邊（`kid_pet_cards`）容許同一張卡出現多次。

## 格式

- `.webp` 最好，`.png` 都得。
- 卡面比例建議 3:4（例如 600×800）。
- 唔使去底。

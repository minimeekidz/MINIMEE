# VO 錄音

**淨係得兩批要錄。** 角色講嘢（寵物、職員、閒人）全部用瀏覽器即時合成嘅
亂語，唔使錄。

稿喺 `docs/design-reference/vo-scripts.md`，照讀就得。

## themes/ —— 36 條主題旁白

每條約 70 字，讀 25–35 秒。

```
themes/theme-01.mp3 … themes/theme-36.mp3
```

| | |
|---|---|
| 語言 | **清楚嘅廣東話**（呢批唔可以用亂語） |
| 語速 | 慢，比平時慢兩三成 |
| 語氣 | 溫暖、講故仔，唔好似讀稿 |
| 停頓 | 每個逗號停半秒，四個詞彙要聽得出分開 |
| 格式 | `.mp3`，44.1kHz，單聲道就夠 |
| 環境 | 靜，唔好有冷氣聲同回音 |

## questions/ —— 36 條問題

每個主題一句，玩遊戲嗰陣問。同樣要清楚廣東話。

```
questions/theme-01-q.mp3 … questions/theme-36-q.mp3
```

## 唔使一次過錄晒

一個月得三個主題。先錄上映緊嗰三個就夠，之後每月補三條追得上：

- `theme-01` 軌道交通
- `theme-08` 綠色公園
- `theme-09` 金錢與商店

# 場景／背景圖放呢度

檔名用細楷英文＋連字號，例如 `town-square.webp`、`school.webp`。
唔好用空格、中文或者大楷。

放好之後，網址就係 `/assets/檔名`。

格式：`.webp` 最好（檔案細），`.png` 都得。

寵物角色圖請放 `pets/` 子資料夾，睇嗰度嘅 README。

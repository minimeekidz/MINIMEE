# MEE 卡圖放呢度

三個資料夾，同一張卡三個版本，**檔名一定要一樣**。程式係靠檔名認卡嘅，
唔使再入表、唔使改 code。

```
public/assets/cards/
  normal/   MEE-001.webp … MEE-024.webp   常規版（24 張，齊）
  flash/    MEE-001.webp … MEE-024.webp   閃耀版（24 張，齊）
  special/  MEE-S01.webp …                特別版（新資料夾，仲未有嘢）
```

## 規格

跟返而家嗰 48 張，唔好改：

| 項 | 值 |
|---|---|
| 尺寸 | **1672 × 941**（16:9 橫向） |
| 格式 | `.webp` |
| 大細 | 約 110–160 KB 一張 |
| 檔名 | `MEE-001.webp`，三位數，前面補零 |

⚠️ **24 張卡全部係 16:9 橫向。** 之前有六個地方將佢哋 crop 成 3:4 直度，
影到人頭都切走咗。新圖照 16:9 出就唔會再撞返呢個問題。

## 覆蓋舊圖

直接用同名檔覆蓋 `normal/` 同 `flash/` 入面嗰 24 張就得 —— 唔使改資料庫，
`card_catalog` 已經指住呢啲路徑。

## 特別版

`special/` 係新開嘅，命名用 `MEE-S01.webp`、`MEE-S02.webp` 咁樣（`S` = special）。

特別版**唔會佔卡冊嗰 24 格**，佢哋擺喺「特別收藏」嗰行。咁樣先唔會令卡冊
有格永遠儲唔到 —— 卡冊 24 格，人人都填得滿。

派發規則仲未定，見 `docs/design-reference/card-rarity-plan.md`。

## 命名 = 唯一嘅表

呢個同貼紙系統一樣：檔名就係身分。改名等於改咗張卡係邊張，所以改名之前
睇清楚 `card_catalog` 邊個 code 對邊個主題。

# MEE卡－特別版（Special）

**而家係空嘅。**

特別版**唔佔卡冊嗰啲格**，擺喺「特別收藏」嗰行 —— 所以佢係唯一一款
可以做年繳專屬而唔會令任何一格永遠儲唔到嘅卡。

## 檔名

跟出處，唔跟主題編號（因為佢唔對主題）：

- 砌齊一本 BOOK 送嗰啲：`book-1.webp` … `book-4.webp`
- 節日：`festival-cny.webp`、`festival-dragon.webp`、`festival-midautumn.webp`
- 生日：`birthday.webp`

規格同其餘兩款一樣：**1672 × 941**，webp。

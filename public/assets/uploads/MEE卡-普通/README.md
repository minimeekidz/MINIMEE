## 檔名

`1_normal.webp` … `36_normal.webp`。個數字係**主題編號**，
對返 `src/data/themeBook.json`：`1` = 軌道交通，`25` = 日常職人，
`36` = 夢想發射台。同一個數字嘅 normal 同 flash 一定要係同一張卡。

規格：**1672 × 941**（16:9 橫向），webp。

⚠️ 全部要 16:9。之前有六個位將卡 crop 成 3:4 直度切走咗人頭，
照 16:9 出就唔會撞返。

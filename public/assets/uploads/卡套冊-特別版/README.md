# 特別版卡套冊

**2 本，每本 4 張 = 合共 8 張。**

特別版**唔佔主題卡套冊嗰 72 格**，佢有自己兩本 —— 所以就算一張特別版
都冇，主題卡套冊一樣可以係完整嘅。呢點係整個派卡規則嘅地基，
唔好搬佢入主題冊。

## 檔名

跟出處改名，唔跟主題編號（因為特別版唔對應任何主題）：

```
book-s1_book-1.webp        砌齊 BOOK-01 送嗰張
book-s1_book-2.webp
book-s1_book-3.webp
book-s1_book-4.webp
book-s2_festival-cny.webp      新年
book-s2_festival-dragon.webp   端午
book-s2_festival-midautumn.webp 中秋
book-s2_birthday.webp          生日（唯一一張月繳都有）
```

一本 4 格，啱啱好：第一本收「砌齊卡套冊」嘅四張，第二本收三個節日
加生日。**呢個分法係我建議，未經你確認**，你想點分都得，
我照跟改個名就是。

如果你要上嘅係卡套冊底圖，叫 `book-s1_cover.webp` / `book-s1_spread.webp`。

規格：**1672 × 941**（16:9 橫向），webp。

# 主題 MEE 卡套冊

**12 本，每本 3 組，每組 1 閃 1 普 = 每本 6 張，合共 72 張。**

12 本 × 3 組 = 36 組，啱啱好 36 個主題 —— 而每個月出 3 個主題，
即係**一個月一本**，一年行完 12 本。

## 檔名

```
book-01_theme-01_normal.webp
book-01_theme-01_flash.webp
book-01_theme-02_normal.webp
book-01_theme-02_flash.webp
book-01_theme-03_normal.webp
book-01_theme-03_flash.webp
book-02_theme-04_normal.webp
…
```

- `book-NN` = 第幾本（01–12）
- `theme-NN` = 主題編號，對返 `src/data/themeBook.json`
- `normal` / `flash` = 普通版／閃耀版

呢個命名嘅重點係**一眼睇得出邊本、邊個主題、邊個版本**，
唔使再開多個對照表。

如果你要上嘅係**卡套冊本身嘅底圖**（唔係入面啲卡），
就叫 `book-01_cover.webp` 同 `book-01_spread.webp`，兩樣可以並存。

規格：**1672 × 941**（16:9 橫向），webp。

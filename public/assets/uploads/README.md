## 幫到手嘅幾點（唔係硬性要求）

**檔案名。** 貼紙同 MEE 卡**個檔案名就係佢個名**：`畫畫.webp` → 貼紙「畫畫」，
`海浪之友.webp` → 卡名「海浪之友」。所以：

- 用中文改名，寫返你想小朋友見到嗰個詞
- 唔好加編號前綴（`01-畫畫.webp` 會變成標籤「01-畫畫」）

寵物 sprite 就相反，**要寫清楚邊隻寵物同咩角度**，例如
`MM_PET_05_海浪企鵝_front_walk.png`。因為切格之後我要對返邊隻係邊隻，
撈亂咗就會出現企鵝行路變咗柴犬。

**Sprite sheet 格式。** 之前跑得最順嗰個係：magenta（`#FF00FF`）底、
每格之間留 20px、front／back／left_side 三個角度、每個角度兩幀。
唔跟到都唔緊要，話我知你點排就得。

**貼紙要去底**（透明背景），正方形，建議 512×512。白底喺深色場景會變一嚿白方格。

**地圖係俯視。** 而家四張都係俯視角，如果新圖係街景視角（人物平視），
就會同現有嘅行走系統對唔上 —— 唔係做唔到，但要你話我知，我要重做一套座標。

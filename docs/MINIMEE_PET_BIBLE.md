## 2. 計分（`00_玩法總規則`）

| 規則 | 數值 | 點解 |
|---|---|---|
| 每日基礎互動 | 每隻寵物 **+1／日**，唔理㩒幾多個 Action | 避免為刷分而重複按 Action；Action 回歸純粹互動 |
| 每日答題 bonus | **全鎮每日只有 2 次**成功答題可 +1 | 鼓勵集中攻略特別鍾意嗰隻，唔係 12 隻同速 |
| 每隻寵物每日上限 | **+2** | 最快 30 點 ≈ 15 日 |
| 每級 | **固定 30 點** | 簡單、可預期 |
| 上限 | **Lv.12 = 330 點**，滿級封頂 | 只互動 ≈ 330 日；固定攻略 ≈ 165 日 |
| 題目資格 | **集齊 4 塊碎片**（完整 MEE 卡）嘅主題先可以被問 | 唔再用「持有 1 塊碎片」 |

### 答題狀態機

```
提問
 ├─ 第一次答啱 ──────────→ +1（如仍有 bonus quota）  記 first_try_correct
 └─ 第一次答錯 ──→ 重答一次（★ 絕對唔可以顯示答案 ★）
      ├─ 第二次答啱 ────→ +1（如仍有 bonus quota）  記 second_try_correct
      └─ 第二次再錯 ────→ +0，唔消耗 quota，該寵物今日題目完結  記 failed
```

**三條最易做錯：**

1. **第一次答錯唔可以顯示答案或者 highlight 正確選項。** 顯示咗，第二次就冇意義。
   `PetEncounter.tsx` 有測試守住，`QA13` 亦都係測呢樣。
2. **答錯唔會消耗每日 2 次 bonus quota。** 小朋友可以順延去搵下一隻。
3. **quota 用晒之後答啱，仍然要稱讚同記成績**，唔可以話「冇分所以唔算」。
   學習紀錄同好感度係兩件事。

## 3. 好感度唔係成績表

Excel 講得好白：「好感度代表關係，不應代替學習成績。」

- **好感度** = 關係 → `pet_friendships`
- **成績** = `first_try_correct` / `second_try_correct` / `failed` / mastered topics → 另外記

一個小朋友日日淨係去打招呼，好感度會升，但成績表唔會靚咗。呢個係故意嘅。

**已做。** `quiz_attempts` 表逐次記低：邊隻寵物、邊個主題、邊個詞、試咗幾多次、
結果（`first_try_correct` / `second_try_correct` / `failed`）、有冇加到好感度。

**每一次都會記，包括冇加分嗰啲** —— 表 07 寫明「即使quota用完，答題結果仍必須
寫入成績紀錄」。記錄同加分喺同一個 transaction 入面（`record_pet_quiz`），
分開做嘅話中間失敗就會出現「加咗分但冇記錄」或者相反。

家長喺小朋友檔案頁見到：一次答啱率、諗多次答返啱嘅數量、問過幾多個詞語、
同埋「可以再溫下呢幾個」。**答返啱之後個詞會自動喺重溫清單消失**
（用每個詞最近一次結果，唔係數總數）。

## 4. 事件系統

優先級（多個事件同時發生時）：

```
安全天氣限制 > 小朋友／寵物生日 > 限時城鎮活動／節日 > 影片更新 > 季節 > 平日
```

**安全永遠最高。** 例如：飛行小雞強風唔飛、海浪企鵝雷暴唔落水、
所有寵物移室內。生日照樣過，但地點自動改室內（`QA17`）。

**事件主要改「世界狀態」，唔係派分。** 獎勵以貼紙、Pose、相框、裝飾、
寵物卡為主，一般唔加好感度 —— 唔好用活動搞亂咗 12 級節奏。

> ⚠️ **仲未做：** 天氣同農曆節日。
> - **天氣**：個 app 冇天氣來源。隻寵物喺大晴天講「落雨啦」，香港小朋友即刻穿煲。
>   要有真 feed 先做得，而 `08_出沒地點規則` 有一整欄係靠天氣㗎。
> - **農曆節日**（新年、中秋、端午）：每年日期都唔同，擺錯日期衰過冇。要一個日曆表。

## 5. 神秘獎勵防刷規則（`03_神秘獎勵`）

**MR01 隨機 roll 只可以喺「當日第一次真正產生 +1 嘅互動」發生一次。**
重複㩒 Action 唔可以重抽 —— 否則就變返做刷獎勵。

固定里程：Lv.6 → 普通版紀念卡（MR02）、Lv.11 → 閃耀版（MR05）。
**唔係** Lv.8／Lv.12 —— 之前版本擺錯咗，已經改返。

## 7. VO 邊度嚟

| 用途 | 來源 | 檔案 |
|---|---|---|
| 答題 6 個狀態 | **Excel 07** | `petBible.ts` → `quizLine()` |
| 8 類事件台詞 | **Excel 06** | `petBible.ts` → `eventVoFor()` |
| 12 個 Action 嘅對白 | Excel 冇提供，**按性格創作** | `src/data/petActionVo.ts` |

Em 嘅指示：「有提供的必須要跟住，沒有提供的你按照佢嘅角色性格同埋口頭禪語氣
風格對話模式習慣等等去創作」。

所以 `petActionVo.ts` 係逐隻寵物、對住 `01_12寵物Master` 嘅
`角色性格` / `說話語氣` / `固定口頭禪` / 各項喜好寫出嚟嘅。
**Excel 之後如果加咗 Action VO 表，就要刪走 `petActionVo.ts` 對應嗰段**，
唔好留兩個來源。

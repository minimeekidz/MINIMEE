# 派卡規則（Em 定案 2026-08-15）

> 呢份唔再係建議 —— 係 Em 拍咗板嘅規則。
> 之前幾版兜圈嘅記錄留咗喺最後「附二」。

## 一句總結

```
4 碎片 = 完成主題 = Normal 必得
年繳    = 同時保證 Flash
月繳    = Flash 可透過稀有機會／活動／升級獲得
Special = 特別時刻額外收藏，不影響 72 張主卡完成率
```

## 1. Normal 係基礎主卡

任何會員，完成該主題 4 個碎片就**必定先獲得 Normal**。

Normal 代表嘅係「我真係完成過呢個主題」。所以**所有小朋友都可以慢慢儲齊
36 張 Normal，主收藏永遠有完成嘅可能**。呢個係唔可以動嘅底線。

## 2. Flash 係同一主題嘅第二張收藏

Flash **唔取代** Normal，係另一張卡、另一個格。

**年繳**：完成 4 碎片 → **Normal + Flash 一次過解鎖**，卡冊一下亮起兩格。✨
細路仔嘅感受係「普通會員有一張，我有兩張，而且第二張靚好多」。

**月繳**：完成 4 碎片 → 先得 Normal。Flash **唔係永久封死**，
可以透過少量機會再攞：

- 限時活動／節日
- 特定友情里程碑
- 神秘獎勵
- 連續完成主題
- **升級成年繳**

所以月繳嘅感覺係「差一張閃卡，好想儲埋」，而唔係「永遠攞唔到，索性放棄」。

## 3. 年繳賣點嘅寫法（好重要）

用呢句：

> **年繳會員：每個完成主題，保證獲得 Normal + Flash 雙版本。**

**唔好**寫「年繳先有 Flash」。差別好大 —— 兩邊卡冊 layout 完全一樣，
年繳只係填得快好多：

```
月繳    01  ☑ Normal   □ Flash
年繳    01  ☑ Normal   ✨ Flash
```

賣嘅係「保證、即時、成套」，唔係「你冇資格」。

## 4. 升年繳補發（課金鈎）

月繳玩咗 5 個主題：

```
01 ☑ Normal  □ Flash
02 ☑ Normal  □ Flash
03 ☑ Normal  □ Flash
04 ☑ Normal  □ Flash
05 ☑ Normal  □ Flash
```

升年繳之後，**已完成但未有 Flash 嘅主題全部補發**：

> 升級年費，即時點亮你已完成主題嘅閃耀收藏。

唔減學習內容，純粹賣收藏升級感 —— 同 MINIMEE 嘅定位一致。

## 5. Special Memories Collection

無主題、無 Normal／Flash 對應、**唔影響 72 張完成率**。

用嚟派嘅時刻：

- 小朋友生日
- 加入 MINIMEE 一周年
- 第一次成功加好友
- 友情周年／好友共同事件
- 寵物好感 Lv12
- 完成某個年度全部主題
- 農曆新年／聖誕／中秋等限定活動
- MINIMEE 特別活動
- 官方 surprise gift

呢啲卡最值錢嘅地方係「**我嗰時先攞到**」，唔係學習獎勵。

一冊 4 張，可以不斷開新頁。未解鎖顯示**朦朧＋鎖頭**。

**完成率唔可以顯示 `7 / 28`。** 日後會不停加新限定卡，
分母一路變大，細路仔就永遠見到自己未完成。要顯示：

> 已收藏 **7** 張特別回憶

## 卡套冊結構

- **主題冊 12 本 × 6 格 = 72**。一本 3 個主題，每個主題一組
  「1 普 1 閃」並排。一個月出 3 個主題 = 一個月一本。
- **特別版冊每頁 4 格**，頁數不封頂。

Normal 同 Flash 放埋同一本係啱嘅，唔使拆兩本。

## 資料庫點做

| 要做 | 點做 |
|---|---|
| 卡分兩種 | `card_catalog.kind` = `theme` / `special` |
| 閃係另一張卡 | 每張卡自己一行；code 用 `T01-N` / `T01-F` / `SP-001` |
| 完成率 | 淨係數 `kind = 'theme'`，所以特別版加幾多都唔影響 72 |
| 年繳 | `subscriptions.plan_type = 'yearly'` 且 `status = 'active'` |
| 完成主題 | `forge_theme_card` 出 Normal；係年繳就連 Flash 一齊出 |
| 升年繳補發 | `backfill_flash(kid_card_id)` —— 有 Normal 冇 Flash 嘅全部補 |
| 活動派閃／派特別版 | `grant_card(kid_card_id, code, reason)` |

`grant_card` 靠 `mee_cards` 嗰個 `(kid_card_id, code)` unique 做冪等 ——
同一張卡派兩次唔會出兩行，所以活動重複觸發都唔會爆。

## 兩件 Em 要留意嘅事

**1. 退訂之後啲 Flash 點算？**
建議：**唔收返**。細路仔已經擁有嘅收藏唔應該因為家長停訂而消失 ——
呢個係會令人恨你嘅嗰種設計。年繳本身係預繳一年，冇乜可以鑽嘅空子。
（未實作，等你講。）

**2. 「連續完成主題」係一個 streak。**
放假、病、旅行都會斷。如果要用，建議用「一個月內完成 N 個」
而唔係「連續 N 個月」—— 前者係鼓勵，後者係壓力。

## 附一：你最初發現嗰個洞，卡套冊本身已經解咗

你最初問：年繳＝閃耀、月繳＝常規，咁**點都會有一款係儲唔到**。

卡套冊定咗每個主題兩個格之後，呢個洞冇咗 —— 兩款各有各位，
唔再係二揀一。Normal 嗰 36 格人人填得滿，Flash 嗰 36 格
月繳都有路攞，只係要撞機會。

## 附二：點解兜咗三個圈

留低做記錄。三個都係我提、Em 打穿嘅：

1. **月繳「四個 round 全對」升級** → 咁年繳動力咪好細？（兩條路同一個終點）
2. **月繳等主題落架先挑戰** → 細路仔會唔開心（等係一件佢做唔到嘢嘅事）
3. **閃耀券自己揀** → 又碎片又券，更加複雜（3–12 歲唔應該有兩種貨幣）

三次都係同一個病：我一路想搵一條「月繳自己努力就攞到 Flash」嘅規則，
但咁樣年繳就冇嘢賣。Em 最後嘅答案係**唔好搵**：Flash 就係年繳嘅保證，
月繳嗰邊唔用固定規則，用**唔定時嘅機會**（活動、節日、里程碑、升級）。
機會唔係規則 —— 佢唔會被人計出「做足 X 就一定有」，
所以年繳嘅價值企得住；但佢又唔係零，所以細路仔唔會放棄。

## B. VO 錄音（2026-08-16 大改）

Em 定咗個方向：**除咗學習影片同詞彙之外，全部角色講嘢都係「亂語」** ——
好似動物森友會、Minion 咁，聽唔出係咩語言，淨係用語氣、音調、快慢演繹。

呢個決定**大幅減少要錄嘅嘢**：由原本 300 幾條，變成 **36 + 36**。
亂語嗰部分連錄都唔使錄，瀏覽器即時合成。

### 🔴 第一批：36 條主題旁白（唯一要「講得清楚」嗰批）

**每條大約 70 字，讀 25–35 秒。** 稿全部寫好，喺
[`vo-scripts.md`](./vo-scripts.md)，照讀就得。

- 檔名：`theme-01.mp3` … `theme-36.mp3`
- 放邊：`public/assets/vo/themes/`

| | |
|---|---|
| 語言 | **清楚嘅廣東話** |
| 語速 | 慢，比平時慢兩三成 |
| 語氣 | 溫暖、講故仔 |
| 停頓 | 每個逗號停半秒，四個詞彙要聽得出分開 |
| 格式 | `.mp3`，44.1kHz，單聲道 |

**唔使一次過錄晒。** 一個月得三個主題，先錄上映緊嗰三條
（`theme-01 軌道交通`、`theme-08 綠色公園`、`theme-09 金錢與商店`），
之後每月補三條。

### 🔴 第二批：36 條問題（一樣要清楚）

每個主題一句，玩遊戲嗰陣問。`theme-01-q.mp3` … `theme-36-q.mp3`，
放 `public/assets/vo/questions/`。稿喺同一份 `vo-scripts.md`。

### ✅ 亂語：唔使錄，瀏覽器即時合成

原本呢度寫住要錄 24 段短聲。**唔使喇** —— Em 決定咗用即時合成，
已經改好：

| | |
|---|---|
| 要錄幾多 | **0 段** |
| 要用邊個 API | **冇** |
| 每次播放成本 | **HK$0** |
| 要落幾多檔案 | **0 bytes** |

四把聲（活潑／溫暖／沉實／柔和）係四條「配方」——
一個振盪器波形、一個基本音高、一個衰減時間。34 隻角色照舊各有各把聲：
程式用角色 ID 派聲線同音高，同一隻永遠一樣。

- 問句尾音會升、感嘆句節奏較快、句子越長聲越多（3 至 10 聲）
- **新對話會中止上一句**，唔會兩三隻一齊嘈
- 靜音掣照舊，撳咗記住
- 加咗低通濾波，square 同 sawtooth 兩把聲唔會刺耳 —— 聽眾係細路

因為冇檔案，所以亦冇「檔案上載失敗就冇聲」呢個問題。

**早更同晚更係兩把唔同嘅聲。** 十個崗位嘅日班夜班全部逐個配咗音色
（例如戲院接待日班係「活潑」、夜班係「沉實」），唔係靠個名去估。
其餘冇特別配嘅角色（18 隻寵物、6 隻閒人）就由 ID 自動派，同一隻永遠一樣。

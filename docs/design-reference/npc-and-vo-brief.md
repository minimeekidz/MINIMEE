## A. NPC —— 一共 12 隻

背景一個角色都冇畫（呢個係規矩），所以有人氣全部靠呢啲 sprite。

### 規格（每隻都一樣）

| | |
|---|---|
| 格式 | `.webp`（或 `.png`），**透明底** |
| 高度 | **512 px** 左右，闊度隨佢 |
| 姿勢 | 企定、面向鏡頭或者略側、**全身** |
| ⚠️ 位置 | **腳底要貼住圖片最底邊** —— 下面留白會令佢浮喺半空 |
| 風格 | 同場景一樣：溫暖歐陸小鎮、厚塗、清晰輪廓 |
| 放邊 | `public/assets/uploads/NPC/`（檔名見下面） |

**Prompt 範本：**

```
Character sprite for a cosy European storybook town game, full body, standing,
facing the viewer, [角色描述]. Transparent background. Feet touching the very
bottom edge of the image. Warm painterly style, clean readable silhouette.
Single character only, NO background, NO scenery, NO shadow on the ground.
```

## B. VO 錄音

### 🔴 第一批：36 條主題旁白（最重要）

**每條大約 70 字，讀出嚟 25–35 秒。** 全部稿已經寫好、已經入咗資料庫，
你淨係要照讀。

- 檔名：`theme-01.mp3` … `theme-36.mp3`
- 放邊：`public/assets/vo/themes/`
- 稿喺邊：`src/data/themeBook.json` 每個主題嘅 `vo` 欄
  （我可以另外導一份純文字稿俾你，講聲就得）

**例（theme-01 軌道交通）：**

> 城市入面有好多沿住路軌行嘅交通工具。港鐵帶我哋去唔同地區，
> 電車慢慢穿過街道，火車可以去更遠地方，新界仲有輕鐵。
> 下次搭車，不妨留意吓佢哋行嘅路線有咩唔同。

**錄音要求：**

| | |
|---|---|
| 語言 | 廣東話 |
| 語速 | 慢，比平時講嘢慢兩三成 —— 對象係 3 歲都要聽得明 |
| 語氣 | 溫暖、講故仔，唔好似讀稿 |
| 停頓 | **每個逗號都停半秒**，四個詞彙之間要聽得出分開 |
| 格式 | `.mp3`，44.1kHz，單聲道就夠 |
| 環境 | 靜，唔好有冷氣聲同回音 |

**一次唔使錄晒 36 條。** 一個月得三個主題，所以**先錄頭三個月嗰九條**
（依家上映嗰三個係 `theme-01 軌道交通`、`theme-09 金錢與商店`、
`theme-08 綠色公園`），之後每個月補三條就追得上。

### 🟡 第二批：36 條問題

每個主題有一條問題，玩遊戲嗰陣問。已經寫好。

- 檔名：`theme-01-q.mp3` … `theme-36-q.mp3`
- 放邊：`public/assets/vo/questions/`
- 稿：`themeBook.json` 每個主題嘅 `question` 欄
- 例：「你最鍾意搭邊一種有路軌嘅交通工具？」

一條得一句，好快錄。同樣先錄上映緊嗰三條。

### ⚪ 第四批：小寵物互動語音（好大工程，可以唔錄）

18 隻寵物 × 12 級互動 = **216 段**。文字稿已經全部寫好
（`src/data/petActionVo.ts`），而家用文字顯示，**唔錄都完全玩到**。

如果想錄，建議**淨係錄第 1 級「打招呼」嗰 18 句**就夠 —— 小朋友最常撳，
而且一隻寵物講一次嘢就已經有生命。

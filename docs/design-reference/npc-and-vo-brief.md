## B. VO 錄音（2026-08-16 大改）

Em 定咗個方向：**除咗學習影片同詞彙之外，全部角色講嘢都係「亂語」** ——
好似動物森友會、Minion 咁，聽唔出係咩語言，淨係用語氣、音調、快慢演繹。

呢個決定**大幅減少要錄嘅嘢**：由原本 300 幾條，變成 **36 + 36 + 24 段**。

### 🔴 第一批：36 條主題旁白（唯一要「講得清楚」嗰批）

**每條大約 70 字，讀 25–35 秒。** 稿全部寫好，喺
[`vo-scripts.md`](./vo-scripts.md)，照讀就得。

- 檔名：`theme-01.mp3` … `theme-36.mp3`
- 放邊：`public/assets/vo/themes/`

| | |
|---|---|
| 語言 | **清楚嘅廣東話** |
| 語速 | 慢，比平時慢兩三成 |
| 語氣 | 溫暖、講故仔 |
| 停頓 | 每個逗號停半秒，四個詞彙要聽得出分開 |
| 格式 | `.mp3`，44.1kHz，單聲道 |

**唔使一次過錄晒。** 一個月得三個主題，先錄上映緊嗰三條
（`theme-01 軌道交通`、`theme-08 綠色公園`、`theme-09 金錢與商店`），
之後每月補三條。

### 🔴 第二批：36 條問題（一樣要清楚）

每個主題一句，玩遊戲嗰陣問。`theme-01-q.mp3` … `theme-36-q.mp3`，
放 `public/assets/vo/questions/`。稿喺同一份 `vo-scripts.md`。

### 🔴 第三批：亂語音庫 —— **得 24 段，錄一次用一世**

呢個係新嘢，亦係最抵做嗰批。

**四把聲 × 每把 6 個音節 = 24 段短聲。** 每段 **0.1–0.2 秒**，
就係一個冇意思嘅音，例如「ba / bo / mi / nu / pe / ta」。

| 檔名 | 聲線 | 感覺 |
|---|---|---|
| `bright-1.mp3` … `bright-6.mp3` | 高、脆 | 細細隻、開朗（松鼠、小雞） |
| `warm-1.mp3` … `warm-6.mp3` | 中、圓 | 友善、日常（柴犬、海狸） |
| `low-1.mp3` … `low-6.mp3` | 低、慢 | 老成、穩陣（水豚、獾） |
| `soft-1.mp3` … `soft-6.mp3` | 輕、氣聲 | 溫柔、細聲（白兔、貓） |

放 `public/assets/vo/babble/`。

**錄嘅時候：** 每個音**單獨、平平地讀一次就得**，唔使加感情 ——
高低快慢係程式加上去嘅。錄完之後：

- 34 隻角色（16 NPC + 18 寵物）**自動各自有把聲** ——
  程式用角色 ID 派聲線同音高，同一隻永遠一樣，唔使你逐隻配
- 一句幾多聲、幾快、尾音升唔升，全部睇返句字本身
  （問號尾音會升、感嘆號會急啲、句子越長聲越多，最多 10 聲）

程式已經寫好晒（`src/lib/babble.ts`）。**冇檔案就靜晒**，唔會出錯。

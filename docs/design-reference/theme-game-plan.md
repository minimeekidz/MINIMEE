# 主題小遊戲：玩法、對應主題、詞彙同素材清單

> 呢份係 `npx vite-node scripts/build-game-plan.mts` 出嘅，唔好直接改。
> 改咗遊戲邏輯（`src/lib/games.ts`）或者主題工作簿之後，行返一次就會更新。

## 點解係七個玩法

碎片拼合室同一時間有六格：每個月新上三個主題，上個月三個繼續留喺牆上面等小朋友
儲完。戲院一次過放呢啲主題嘅學習影片，所以**牆上面六個主題，六個玩法都唔可以撞**。
七個玩法排成一個七格循環，任何連續六格都一定唔同 —— 就算有個主題壓多一個月都唔會撞。
呢個規則係寫死喺資料庫度（`theme_releases` 嘅 partial unique index），唔係靠後台提醒。

每個主題都要玩**四次**先砌到一張 MEE 卡，一次一塊碎片。四個 round 一次難過一次：
第一 round 認得出就得，第四 round 要自己講／自己砌／自己做。
小朋友重複玩已經砌完嘅主題，題目會重新抽過 —— 玩法一樣，題目唔同。

### VO 旁白（每個主題一段，已經入咗資料庫 `themes.vo`）

**1. 軌道交通（數一數）**

> 城市入面有好多沿住路軌行嘅交通工具。港鐵帶我哋去唔同地區，電車慢慢穿過街道，火車可以去更遠地方，新界仲有輕鐵。下次搭車，不妨留意吓佢哋行嘅路線有咩唔同。

答句式：`我最鍾意搭{answer}。`

**2. 金錢與商店（講句子）**

> 城市入面有好多唔同商店。超市可以買日用品，麵包店有新鮮食物，書店可以揀書，玩具店就有好多有趣玩具。買嘢之前，可以先諗清楚自己真正需要啲咩。

答句式：`我最想行{answer}。`

**3. 綠色公園（搵一搵）**

> 公園係城市入面一個可以慢落嚟嘅地方。大樹提供樹蔭，小草鋪滿地面，花朵令環境更有顏色，行攰咗仲可以坐喺長椅休息。綠色空間令城市舒服好多。

答句式：`我去公園最鍾意見到{answer}。`

**4. 藍天與海洋（估下會點）**

> 天空同海面都有唔同交通工具。飛機飛得又高又遠，直升機可以喺空中停留同轉向；海上有大型輪船，亦有靠風力前進嘅帆船。佢哋用唔同方法帶我哋去唔同地方。

答句式：`我最想坐{answer}。`

**5. 神秘深海（砌一砌）**

> 海面以下有一個好大嘅世界。小魚成群游過珊瑚，章魚有好多靈活嘅觸手，鯊魚係海洋捕食者，而海龜就會游過好遠嘅海域。海洋動物各有自己嘅生存方法。

答句式：`我最想觀察{answer}。`

**6. 沙灘探索（跟住做）**

> 去沙灘可以發現好多細節。腳下有沙，岸邊可能見到貝殼，用水桶可以裝沙同海水，陽光猛烈時就要戴太陽帽做好防曬。玩得開心之餘，都要記得保護自己同海灘。

答句式：`去沙灘我最想帶{answer}。`

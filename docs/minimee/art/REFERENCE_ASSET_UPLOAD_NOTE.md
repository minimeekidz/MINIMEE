# Reference Asset Upload Note

The curated reference index uses existing/approved MiniMee visual assets by filename. Keep reference images physically separate from governance/spec files. Recommended repo structure:

- `docs/minimee/art/` — rules, prompt locks, reference index
- `assets/reference/minimee/characters/` — character identity anchors
- `assets/reference/minimee/gameplay/` — gameplay/world mood anchors
- `assets/reference/minimee/entrance/` — entrance/loading visual anchors
- `assets/reference/minimee/ui/` — Interaction UI / Zoom UI anchors

Do not duplicate large images if the same canonical asset already exists elsewhere in the repo; point the index to the existing canonical asset path instead.

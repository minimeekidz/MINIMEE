# MiniMee Reference Selection Policy

## Why a shortlist is required
Too many simultaneous references create style conflict and authority confusion. Use the curated Style Reference Index first; bring in additional archive images only when the shortlist lacks a specific visual cue.

## Authority order
1. Character anchors
2. Core gameplay/world anchor
3. Relevant canonical scene visual anchor
4. Relevant UI/entrance anchor
5. Additional archive image only when necessary

## Geometry override rule
No reference image—however attractive—may override route, door, entrance, collision, object-coordinate or safe-area requirements from the Scene System and manifests.

## Generation rule
Prefer 3–6 carefully selected references for one image-generation task. Assign each a role: identity, style, composition, UI, lighting, entrance, or visual-only. Never present a visual-only reference to an agent as geometry authority.

# MiniMee Art Source-of-Truth

For any MiniMee image-generation or visual-art task, read in this order:

1. `MINIMEE_VISUAL_DIRECTION_BIBLE.md`
2. `MINIMEE_GAMEPLAY_ART_LOCK.md`
3. `MINIMEE_SCENE_PROMPT_LOCK.md`
4. `MINIMEE_STYLE_REFERENCE_INDEX.md`
5. `MINIMEE_REFERENCE_SELECTION_POLICY.md`
6. `MINIMEE_COORDINATE_POLICY.md` when world/UI coordinates are relevant
7. Relevant Scene System / scene manifest / UI registry

Reference images control style, mood, rendering density, lighting and UI/character language. They do not control gameplay geometry unless explicitly designated by a canonical manifest.
